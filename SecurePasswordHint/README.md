# Secure Password Hint Tool

A beginner Python project that creates a secure password hint by displaying only the first and last characters of the user's password.

## Features 

- Accepts a password from user
- Removes accidental white space
- Retrives the first and last characters
- D isplays the hint in uppercase
- Uses f-string for formatted output

## Technologies

- Python 3

## Concepts

- Variables 
- User Input
- String Methods
- String Indexing
- .strip()
- .upper()
- f-strings
