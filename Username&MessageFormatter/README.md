# Usernmae and Message Formatter

A beginner Python project that collects a user's first name , last name and bio , then formats the information into a clean user profile using Python string methods.

## Features

- Collects user information
- Creates a username automatically
- Formats names using Title Case
- Removes unnecessary whitespace using .strip()
- Replaces text in the bio
- Counts bio charaters
- Display a formatted profile

## Technologies

- Python 3

## Concepts

- Variables
- User Input
- String Manipulation
- String Methods
- String Indexing
- f-string
- len()
- strip()
