# Multi-Function Calculator

A beginner Pythong calculator  that perfoms six aithmetic operations while safely handling division by zero.

## Features

- Accepts 2 numbers from user
- Performs: Addition, Subtraction, Multiplication, Division, Floor Division and Modulus
- Rounds results to 2 decimal places.
- Handles division by 0 gracefully
- Display results in a formatted table

## Technologies

- Python 3

## Concepts Practiced

- Variables
- User Input
- float()
- Arithmetic operations
- round()
- if statement
- Division by Zero handling
- f-string
