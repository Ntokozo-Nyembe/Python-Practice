# South African Fuel Cost Calculator

A beginner Python project that estimates the fuel cost of a trip based on the travel distance and the curent petrol price.

## Features

- Accepts travel distance in kilometers
- Accepts petrol price per liter
- Calculates  fuel required (1 liter per 10km)
- calculates the estimated fuel cost
- Rounds the final cost to two decimal place
- Display results usng formatted output

## Technologies

- Python 3

## Concepts Practiced

- Variables
- User Input
- float()
- Arithemtic Operations
- round()
- f-string
